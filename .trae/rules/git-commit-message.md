### 语言要求

- 所有 Git Commit Message 必须使用简体中文。
- 仅允许 Commit 类型标识（type）使用英文，例如：feat、fix、docs、style、refactor、perf、test、chore。
- 除 type 标识外，Commit Message 的其他所有内容必须使用简体中文。
- 禁止在描述部分使用英文、繁体中文或中英文混杂表达。

### Commit 格式

必须严格遵循以下格式：

<type>: <中文描述>

例如：

feat: 新增规则订阅自动更新功能

fix: 修复规则导入时进度显示错误的问题

refactor: 重构规则解析模块提高代码可维护性
