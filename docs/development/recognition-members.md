# 云控赞助者名单维护

赞助者名单由 GitHub 仓库远程驱动：根目录 `recognition_members.json`（数据）与 `avatars/`（头像）。修改后推送
到 `main` 分支即对所有客户端生效，无需发版。客户端进入名单页时拉取最新配置，校验通过后原子写入本地
缓存；网络异常或校验失败时降级展示上一次成功的缓存。

## 配置格式

根字段：`version`（整数，建议递增）、`sponsors`（赞助者）。

成员项：

| 字段 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `name` | String | 是 | 昵称，不可为空，名单内不得重复 |
| `avatarFileName` | String | 否 | 头像文件名；缺省或为空时使用内置 `default_avatar.png` |
| `count` | Integer | 否 | 同一人多次赞助时填累计次数（1–9999），缺省为 1；大于 1 时界面在昵称后显示 `×N` 角标 |
| `frame` | String | 否 | 头像框，目前仅支持 `rainbow`（头像边缘一圈流动的彩色光环），缺省或为空时无头像框；其它取值会让整份配置校验失败 |

约束：展示顺序与数组顺序一致；`name` 与非空 `avatarFileName` 不得重复。

头像框由 `frame` 决定，`rainbow` 会在头像内缘画一圈约 4 秒转一周的彩色光环（头像本身略向内缩，行高不变）；
旧版客户端会忽略该字段，只显示普通头像。

## 头像规范

- 文件名匹配 `^[a-z0-9_]+_avatar\.jpg$`，例如 `alone_avatar.jpg`。
- 统一 JPG（内置缺省头像为 PNG），推荐 256×256 或 512×512 正方形，单张压缩到 100KB 以内。
